# 고정 gentle 기준 PESQ 2.4 이상 탐색 — 실험 코드

고정 기준은 gentle입니다. 원래 submission_joint_growth 폴더의 Python 소스 12개가 변경되지 않았음을 SHA-256으로 확인했습니다. GitHub는 수정하지 않았습니다. 이번 선호 실험안은 raw3이며, 이를 새 고정 기준으로 자동 전환하지 않았습니다. 이 문서는 정식 AI 활용 내역서가 아닙니다.

## 변경 원리

- gentle의 기존 잡음 제거, 피치/저역 복원, 웨이블릿 축소, 양방향 처리와 분석 위치 4개 평균을 유지합니다. 새 실험은 그 뒤의 제한된 대역별 이득 보정입니다. 메인 필터 설정은 기존과 같으며 후처리에서 음색과 대역별 이득이 변합니다.
- flat40: 500 Hz 중심의 부드러운 1 dB 추가 보정, 전체 RMS를 gentle에 맞춘 뒤 피크 여유를 둡니다.
- voice40: 처리 음성에서 추정한 잡음 PSD와 국소 전력으로 신뢰도를 계산하고, 신뢰도에 따라 최대 1.25 dB까지 같은 대역을 복원합니다.
- phase40: 시간축 위상 2차 차분으로 만든 안정성 지표를 추가해 안정적인 성분을 더 선택적으로 복원합니다. 두 마이크 사이의 일반적인 coherence 계산과는 다른 자체 휴리스틱입니다.
- raw2/raw3: 신뢰도 계산에 같은 파일의 원본 Noisy STFT를 사용합니다. 에너지가 낮은 완전한 프레임 10%의 주파수별 중앙값을 바탕으로 잡음 PSD를 추정하고, 국소 전력/추정 잡음 비율에 따라 최대 2 또는 3 dB 이득을 줍니다. 별도 잡음 녹음이나 Clean 입력이 필요하지 않습니다.
- 후처리는 전체 RMS를 입력 gentle 출력에 맞춥니다. 피크가 0.999를 넘으면 파일 전체의 이득을 조금 낮춰 파형을 유지합니다. Clean을 이용한 출력 이득 보정이나 평가 전 정답 정렬을 하지 않습니다.

모든 파라미터와 선택 규칙은 코드에 고정되어 있고 해당 Noisy만 사용합니다. 딥러닝/머신러닝 모델, 학습 가중치, 파일명별 정답 규칙을 사용하지 않습니다. 위상/PSD 기반 신뢰도와 이득 함수는 직접 만든 전통적 신호 처리 실험이며 특정 논문을 그대로 복제한 구현이라고 주장하지 않습니다.

## 음질 확인과 제한

사용자는 첫 비교 구간 speaker015_utt01_seg0002에서 voice40을 gentle/flat40보다 선호했고, 다음 비교에서 raw3을 voice40보다 선호했습니다. 다른 파일 전체의 청취 확인을 마쳤다는 뜻은 아닙니다.

raw3의 정답 기준 잡음 우세 시간·주파수 구간 오차는 gentle보다 약 5.4% 감소하고, 고립 오차 피크의 대리 지표는 약 16% 감소했습니다. 반면 음성 우세 구간의 파형 오차는 약 61% 증가했습니다. SNR 하락 및 음색 변화와 함께 해석해야 하며 대리 지표를 실제 금속성 잡음의 감소율로 부르면 안 됩니다. STOI도 소폭 낮아졌습니다. 수치 상승만으로 모든 음질이 그대로라고 단정하지 않습니다.

최종 Validation WAV의 한계값 샘플은 새 후보 전부 0개였습니다. 추가 Train96에서 계측한 크기 복원/웨이블릿 복원 단계의 full-scale 초과는 0개였습니다. 모노/스테레오/44.1 kHz/짧은 입력/무음의 형식 검사 5건과 실제 음성 3구간×5방법의 저장 파형 일치 검사 15건을 통과했습니다. 이 검사는 모든 샘플링 주파수에서의 음질 보장을 의미하지 않습니다.

주파수 드리프트와 진폭 변동까지 추적하는 간섭 제거도 시험했으나 실제 데이터에서 유의한 개선이 없거나 PESQ가 낮아 최종 실험안에 적용하지 않았습니다. 불확실한 성분을 더 억제하는 변형도 선별 평가에서 PESQ가 낮아 제외했습니다.

## 실행

Python 3.13, requirements.txt의 환경에서 검증했습니다. 이 폴더에서:

    python -m pip install -r requirements.txt
    python denoise.py --method raw3 --input input --output output

청취에서 먼저 선호했던 2.4062 후보는 --method voice40, 고정 기준은 --method gentle입니다. 옵션을 생략하면 gentle이 실행됩니다. 입력 바로 아래 모든 WAV를 같은 파일명으로 출력하며 샘플링 주파수·채널 수·샘플 수를 유지합니다. 짧은 입력과 무음은 그대로 출력합니다.

상위 폴더에 원본 validation/ 및 train/이 있을 때 재평가:

    python evaluate.py --method raw3
    python evaluate.py --method voice40

재현 환경은 OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1입니다. research_results에는 파일별 점수, 실제 사용한 평가 스크립트와 고정 파라미터가 있습니다. 코드는 데이터 위치에 개인 PC 절대 경로를 사용하지 않습니다.
